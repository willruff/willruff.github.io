FlexVault

Swift CoreML iOS 2025

FlexVault is a privacy-focused fitness tracking mobile application that leverages AI-powered pose classification to help users track their fitness progress. Built with Swift and CoreML, it provides intelligent analysis of progress photos while maintaining complete user privacy. Watch the demo video to see the app in action!

Key Features

  • AI-powered pose classification using CoreML
  • Privacy-first design with local data storage
  • Progress photo analysis and tracking
  • Weight tracking and goal management
  • Export functionality for data portability

Stock Script

Python textX DSL 2024

Stock Script is a domain-specific language (DSL) designed to simplify financial modeling and stock analysis. Built with Python and textX, it provides an intuitive syntax for declaring stocks, performing operations like splits and merges, and analyzing market data.

Key Features

  • Intuitive stock declaration syntax
  • Advanced operations (splits, merges, price adjustments)
  • Cryptocurrency support and market simulation
  • Human-readable output and customizable display
  • Extensible architecture for custom operations
